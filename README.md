# 멧챠 보물찾기

캠핑장 같은 곳에서 여럿이 폰 카메라로 같이 하는 보물찾기 웹게임. 설치·서버 없이 GitHub Pages에서 돈다.

## 흐름
1. 진행자: `새 보물찾기 만들기` → 범위(20/40/70m)·상자 수·1/2/3등 개수와 상품 이름 → `📍 여기를 중심으로 보물 숨기기`.
2. 진행자 화면의 QR(또는 링크)로 참가자가 들어와 별명·팀을 고른다.
3. 멀리선 아무것도 안 보이고 신호(0~5칸)와 휘파람만 잡힌다. 가까워질수록 신호가 강해지고, `🔍 찾기`를 누르면 약 15m 안의 상자만 카메라에 나타난다(45초).
4. 약 10m(+GPS 오차) 안에서 상자를 누르면 열림 → 1/2/3등 또는 꽝. 먼저 연 사람만, 모든 폰에 바로 공유.

## 구조
- 링크에 설정과 무작위 씨앗이 들어 있어서, 모든 폰이 **똑같은 상자 위치와 당첨**을 계산한다. 위치는 폰 밖으로 안 나간다.
- "누가 들어왔나 / 누가 몇 번 상자를 열었나"만 공개 중계(ntfy.sh)의 추측 불가능한 방 주소로 오간다. 먼저 도착한 메시지가 이긴다.
- 로컬 미리보기: `node server.mjs` → http://localhost:5180

## 한계
- 카메라·위치·나침반은 HTTPS에서만 된다(GitHub Pages는 HTTPS).
- GPS라 폰마다 수 미터 차이가 난다. 여는 거리를 넉넉히 뒀다.
- 나침반이 없는 기기는 화면을 좌우로 끌어서 둘러본다.
